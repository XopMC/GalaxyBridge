# Contributing / Участие

Focused fixes, reproducible bug reports, device testing, and native-speaker translation reviews are welcome. Read the [contributing guide](docs/public/contributing.md#english), [build guide](docs/public/build.md#english), and [roadmap](docs/public/roadmap.md#english). Report issues with the [templates](https://github.com/XopMC/GalaxyBridge/issues/new/choose); omit personal content and credentials.

Приветствуем небольшие исправления, воспроизводимые сообщения об ошибках, проверки на устройствах и проверку переводов носителями языка. Прочитайте [правила участия](docs/public/contributing.md#russian), [инструкцию сборки](docs/public/build.md#russian) и [планы](docs/public/roadmap.md#russian). Для обращений используйте [шаблоны](https://github.com/XopMC/GalaxyBridge/issues/new/choose); не добавляйте личное содержимое и секреты.

Contributions to the project’s own code use the [MIT License](LICENSE). / Вклад в собственный код проекта распространяется по [лицензии MIT](LICENSE).
